# Pull request footer

Close every pull request body with one line naming the logs it touched.

Grammar: `Logs:`, then the log names separated by commas, each optionally followed by its entry IDs in parentheses, separated by commas.

`Logs: CHANGELOG, TECHNICAL_NOTES, BUGS (BUG-004, BUG-005), POTENTIAL_GAPS (GAP-002)`

If it touched none: `Logs: none.` Place the line last in the project's pull request template.

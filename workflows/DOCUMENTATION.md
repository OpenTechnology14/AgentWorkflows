# Documentation and source ownership

> **Status:** Maintained reusable workflow

- This library owns generic workflows and templates. Live project records and confidential source evidence belong in the user's private workspace.
- Edit maintained sources under workflows/, templates/ and packaging/. Generated plugin files come from `python3 scripts/build.py`; check drift before release.
- Each project retains its instruction generators, canonical queue, design decisions and acceptance rules. Companion records link to the authority instead of duplicating it.
- Preserve IDs, question history, source revisions and actual delivery states. A moved record needs a clear pointer and checked destination.
- Do not submit private reports, raw project archives, credentials, workstation paths or runtime IDs to this public repository. Use synthetic examples.
- Update affected workflow, template, package and tests together. Verify content claims against source; document unavailable evidence honestly.
- Do not describe generated bundles or offline checks as live model, provider or deployment acceptance.

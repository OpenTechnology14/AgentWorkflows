# Security and privacy

Keep secrets, runtime configuration and live project reporting outside this public repository and its packages. Use synthetic fixtures for issues and examples.

The compiler uses an explicit source list and checks path containment. It makes no network requests, installs no runtime and dispatches no agent work. A package is instructions, not authorization.

Report suspected vulnerabilities privately through the repository maintainer's available private reporting channel; do not post credentials or operational data in public issues. If no private channel is offered, request one without sensitive details. Automated scans are limited indicators, not proof that arbitrary new content is safe to publish.
